# Fate / Encore

> 이루지 못한 소원에, 다시 한번 박수를.

전기 비주얼노벨 『Fate / Encore』의 공개 사이트다. 후쿠오카현 우키하에서 벌어지는 **제6차 성배전쟁**을 다룬다. 일곱 명의 마스터와 일곱 기의 서번트, 발신인 없는 초대장, 해가 기울면 도시에 섞여드는 설명할 수 없는 풍경이 이야기의 뼈대다.

사이트가 곧 작품이다. 설정 자료집이 아니라 모바일 게임 클라이언트처럼 움직인다. 타이틀에서 로비로 들어가고, 서곡은 비주얼노벨처럼 재생되며, 소환은 연출로 보여 준다.

- 주소: <https://fate-encore.site>
- 제작: Wuthering Heights

> 본 저장소는 TYPE-MOON 작품을 좋아하는 사람이 만든 **비공식 팬 제작물**이며, 저작권자 및 관련 회사와 아무런 관계가 없습니다. 등장하는 영령·등장인물·각본은 전부 창작이거나 퍼블릭 도메인 인물을 바탕으로 합니다.

## 바로 열어 보기

의존성도 빌드 과정도 없다. `index.html`을 브라우저로 열면 바로 동작한다.

실제 배포 환경과 똑같이 보려면 저장소 폴더에서 간단한 서버를 띄운다.

```sh
python -m http.server 5173
# → http://localhost:5173
```

- 처음 열면 `TAP TO START` 뒤에 서곡이 한 번 재생된다. 다시 보려면 주소 끝에 `?intro`를 붙인다.
- `TAP TO START`를 거치는 건 브라우저가 사용자가 한 번 누르기 전에는 소리를 내 주지 않기 때문이다.

## 파일 구성

```
index.html              화면 전체 (타이틀 · 로비 · 메뉴 화면 · 서곡 · 프로필)
assets/css/style.css    전체 스타일과 디자인 토큰
assets/js/main.js       참전 명단(ROSTER) · 화면 전환 · 로비 대사 · 소환 · 서곡 플레이어 · 프로필 · 소식지
assets/js/cast.js       서번트 설정 ─ 진명이 열쇠
assets/js/masters.js    마스터 설정 ─ 마스터 이름이 열쇠
assets/js/prologue.js   서곡 스크립트와 배경 · 효과음 · 일러스트 경로
assets/js/chapters.js   스토리의 막 목록과 루트 차트 ─ 막을 여는 곳
assets/img/             로고 · 영주 · 서번트 그림 · 서곡 배경(story/) · 장식(deco/)
assets/audio/bgm.mp3    배경음악
tools/compose-room.py   서곡 방 장면에 봉투와 초대장을 합성하는 스크립트
DESIGN.md               디자인 시스템 ─ 색 · 글꼴 · 부품 · 해야 할 것과 하지 말 것
PRODUCT.md              이 사이트가 누구를 위해 무엇을 하는지
CNAME                   도메인 (fate-encore.site)
```

새로 공개할 때는 거의 언제나 **데이터 파일만** 고치면 된다. `main.js` 맨 위의 `ROSTER`, `cast.js`, `masters.js`, `prologue.js`, `chapters.js`다.

## 내용 고치기

### 서번트 공개하기

참전 명단은 `assets/js/main.js` 맨 위의 `ROSTER`다. 클래스 순서대로 일곱 줄이고, `name`이 없는 줄은 미공개 카드가 된다.

```js
{ cls: 'CASTER', name: '진명', master: '마스터 이름',
  line: '한마디',                                   // 로비 대사창과 프로필에 같이 쓰인다
  glyph: svg('…'),                                  // 그림이 없을 때 쓰는 클래스 문양
  art:  'assets/img/servant-이름.webp',             // 선택 ─ 로비 아치의 전신
  bust: 'assets/img/servant-이름-bust.webp',        // 선택 ─ 프로필 사진 칸의 상반신
  face: 'assets/img/servant-이름-face.webp',        // 선택 ─ 캐스트 카드 · 소환 카드의 얼굴
  masterGlyph: seal('assets/img/seal-이름.png'),    // 선택 ─ 영주 그림
  masterGlyphCredit: '@아이디' },                   // 선택 ─ 영주를 다른 사람이 그렸을 때
```

공개하려면 그 줄에 `name` · `master` · `line` · `glyph`를 채우고, `cast.js`에 같은 이름으로 설정을 넣는다. `name`은 `cast.js`의 열쇠와 글자가 같아야 설정이 붙는다.

### 서번트 설정 채우기

`assets/js/cast.js` 하나만 고치면 된다. 진명이 열쇠이고, 비워 둔 항목은 `—`로 나온다.

```js
'오스카 조로아스터': {
  gender: '남성', alignment: '星', height: '183cm', weight: '71kg',
  stats: { str:'C', end:'B', agi:'B', mgi:'EX', lck:'B', np:'A+' },
  npName: '에머랄드 빛 끝에서 그대를 기다리리',
  npAlias: '에우리온 아틀리에 · Eurion Atelier',   // 선택 ─ 이명
  npType: '결계보구',                             // 선택 ─ 종별
  npRange: '10~99',                              // 선택 ─ 렌지
  npTargets: '50명',                             // 선택 ─ 최대포착
  np: [ '첫 문단.', '“따옴표로 시작하고 끝나면 대사체가 된다.”' ],
  skills: [
    { kind:'클래스 스킬', name:'진지작성', rank:'B', title:'손님을 위한 별궁',
      text: [ '문단 하나가 배열 항목 하나다.' ] }
  ],
  bio: [ '소개문도 문단 배열이다.' ],
  lore: [                                         // 설정 탭
    { heading: '', text: [ '소제목 없는 머리말.' ] },
    { heading: '그가 남긴 업적',
      table: { head: ['분야','대표 업적','후대의 평가'], rows: [ ['회화','작품명','평가'] ] },
      text: [ '표 아래에 이어지는 문단.' ] }
  ]
}
```

- `stats`의 열쇠: `str` 근력 · `end` 내구 · `agi` 민첩 · `mgi` 마력 · `lck` 행운 · `np` 보구
- `kind`에는 `클래스 스킬` · `보유 스킬 ①` · `고유 능력`처럼 아무 분류나 쓴다. `title`(스킬 부제)이 없으면 `''`로 두면 그 줄이 빠진다.
- `npAlias` · `npType` · `npRange` · `npTargets`는 적어 둔 캐릭터에게만 줄이 생긴다.
- `「` `『` `“` `‘`로 **시작하고 닫는 따옴표로 끝나는** 문단은 코발트 세로선이 그어진 대사체가 된다. `“잘했어”라는 말은…`처럼 인용으로 시작하는 서술문은 본문으로 남는다.
- `**별 두 개**`로 감싸면 짙은 코발트 강조, 문단 안의 `\n`은 줄바꿈이다.
- `lore`에서 `heading`을 비우면 소제목 없이 문단만 나온다. `table`은 넣은 덩어리에만 그려지고, 좁은 화면에서는 세로로 풀린다.

### 마스터 설정 채우기

`assets/js/masters.js`다. 마스터 이름이 열쇠이고, 어느 서번트와 짝인지는 `ROSTER`가 정한다. 비워 둔 항목은 `—`로 나온다.

| 항목 | 내용 |
| --- | --- |
| `gender` · `age` · `height` · `weight` | 성별 · 나이 · 신장 · 체중 |
| `affiliation` | 소속 · 직업 |
| `magic` | 마술 계통 |
| `line` | 한마디. 비우면 인용칸이 사라진다 |
| `bio` | 소개 문단 배열 |
| `lore` | 설정 탭. `cast.js`의 `lore`와 같은 꼴 |

### 그림 넣기

| 그림 | 넣는 곳 | 메모 |
| --- | --- | --- |
| 서번트 | `ROSTER`의 `art` · `bust` · `face` | 배경이 투명한 그림이 가장 잘 어울린다. 없으면 클래스 문양이 나온다 |
| 영주 | `ROSTER`의 `masterGlyph: seal('…')` | 배경이 투명한 PNG. 서곡의 붉은 문양 장면에도 빨갛게 떠오른다 |
| 영주 출처 | 같은 줄의 `masterGlyphCredit: '@아이디'` | 프로필의 영주 아래에 "영주 디자인 @아이디"가 붙는다. [크레딧](#크레딧)도 같이 고친다 |
| 제호 로고 | `assets/img/logo.png` 덮어쓰기 | 비율이 달라지면 `index.html`의 `width` · `height`도 고친다. 글자가 검은색이라 어두운 바탕에서는 보이지 않는다 |
| 로비 배경 | `style.css`의 `--lobby-bg` 한 줄 | |
| 배경음악 | `assets/audio/bgm.mp3` 덮어쓰기 | 출처도 같이 고친다 |

그림을 못 불러오면 깨진 그림 대신 원래 문양이 나온다. 영주는 '영주 그림을 불러오지 못했어요'가 나온다.

### 서곡 고치기

스크립트는 `assets/js/prologue.js`의 `PROLOGUE`다. 위에서부터 한 줄씩 실행된다.

| 줄 | 하는 일 |
| --- | --- |
| `{ bg:'키' }` | 배경 바꾸기 (화면의 글이 지워진다) |
| `{ narr:'글' }` · `{ notice:'글' }` | 내레이션 · 안내문 한 문단 |
| `{ letter:'글', hand:true }` | 종이 카드. `hand`는 다른 필체 |
| `{ place:'글' }` | 화면 아래 지명 자막 |
| `{ cg:'키', text:'지문' }` | 일러스트 한 장. 그림이 없으면 지문이 자막처럼 나온다 |
| `{ fx:'이름' }` | 연출 ─ `light` `reveal` `lighton` `window` `open` `confetti` `seals` `glass` `sealdraw` `sealfull` `nightfall` |
| `{ bgm:0.2 }` · `{ sfx:'키' }` | 배경음악 크기(0~1) · 효과음 |
| `{ wait:1500 }` · `{ clear:true }` | 잠깐 멈춤(ms) · 글 지우기 |
| `{ title:true }` · `{ end:true }` | 타이틀 화면 · 끝 |

배경 · 효과음 · 일러스트 파일은 같은 파일의 `PROLOGUE_ASSETS`에 적는다. 비워 둔 배경은 코드로 그린 임시 배경이 대신한다.

| 배경 키 | 장면 | 그림 |
| --- | --- | --- |
| `black` | 검은 화면 | ─ |
| `window` · `windowLit` | 첫 창문 ─ 불 꺼진 방과 불 켜진 방 | `story/window-*.jpg` |
| `ukiha` · `ukihaNight` | 저녁 무렵의 우키하와 같은 거리의 밤. `fx:'nightfall'`에서 노을 위로 밤이 번진다 | `story/ukiha-sunset.jpg` · `ukiha-street.jpg` |
| `room` | 방, 탁자 위 봉인된 봉투 | `story/room-envelope.jpg` (합성) |
| `envelope` | 봉투 확대 ─ 봉투는 코드로 그린다 | `story/envelope-desk.jpg` |
| `montage` | 안내문 ─ 초대장이 놓인 방에서 시작해 우키하 풍경이 5.5초마다 교차 | `story/room-letter.jpg` + `PROLOGUE_ASSETS.montage` |
| `roomLetter` · `pov` | 초대장이 놓인 방 · 당신의 시점(손등의 영주는 코드로 얹는다) | `story/room-letter.jpg` |
| `void` | 붉은 문양이 떠오르는 어둠 | **비어 있음** |
| `alley` | 해가 진 뒤의 골목 | `story/ukiha/02-backstreet.jpg` |
| `windows` | 불 켜진 창문들 사이 어두운 창 하나 | `story/ukiha/08-red-tower.jpg` |

- 가로로 긴 그림이 좋다. 폰에서는 가운데 부분만 보인다.
- 그림을 넣으면 그 장면의 임시 배경과, 임시 배경에 붙어 있던 연출(봉투가 열리는 것, 유리창에 비치는 형상)도 같이 사라진다. 불빛 · 색종이 · 영주는 배경과 상관없이 나온다.
- 첫 창문의 두 그림은 같은 구도여야 한다. 불빛 자리는 `main.js`의 `SPOT`과 `style.css`의 `50.1% 41.2%`(그림 기준 비율)다.
- 창문들 장면의 어두운 창 위치는 `style.css`의 `49.6% 44.8%`다. 그림을 바꾸면 같이 고친다.
- 방 장면의 봉투와 초대장은 `tools/compose-room.py`로 합성했다. 위치를 바꾸려면 그 파일을 고쳐 다시 실행한다.
- 효과음은 상단 BGM 버튼을 끄면 같이 꺼진다.

### 막 열기

스토리 화면에서 서곡 아래 가로 네 칸이 `assets/js/chapters.js`의 `CHAPTERS`로 그려진다.

```js
window.CHAPTERS = [
  { no: '1', title: '제1막', sub: '루트 차트', route: [ … ] },          // 누르면 루트 차트
  { no: '2', title: '제2막', sub: '부제', script: [ { narr: '…' } ] },  // 누르면 재생
  { no: '3', title: '제3막' },                                          // 잠긴 막
];
```

- `route`도 `script`도 없으면 잠긴 막이다. 부제 자리에 '비공개'가 나온다.
- `route`를 넣으면 누를 때 그 막의 **루트 차트**가 열린다(아래).
- `script`를 넣으면 서곡과 같은 플레이어로 재생된다. 줄의 종류와 배경 키도 서곡과 같다. 끝까지 보면 스토리 목록으로 돌아오고 CLEAR가 붙는다. 서곡만 끝나면 소환 화면으로 넘어간다.
- 스토리 화면 위의 한 줄 설명은 열린 막의 수에 맞춰 저절로 바뀐다.

### 루트 차트

막의 갈래와 엔딩을 한눈에 보는 지도다. 위에서 아래로 흐르는 본편 줄기에서, 선택지마다 갈래가 옆으로 뻗어 엔딩으로 끝난다. 크림 노트 위에 별자리를 잇듯 그린다. 지금은 제1막에 내용 없이 뼈대만 들어가 있다(분기 4 · BAD END 6 · 끝은 제2막으로).

```js
route: [
  { type: 'start' },                                  // 막의 시작
  { type: 'scene' },                                  // 장면
  { type: 'choice', branches: [                       // 선택지 — 갈래는 두 개까지
    [ { type: 'end', kind: 'bad' } ],                 //   첫 갈래는 오른쪽
    [ { type: 'scene' }, { type: 'end', kind: 'bad' } ],  //   둘째 갈래는 왼쪽
  ] },
  { type: 'end', kind: 'next' },                      // 줄기의 끝 — 다음 막으로
]
```

| 칸 | 모양 |
| --- | --- |
| `start` | 이중 원 |
| `scene` | 코발트 점 |
| `choice` | 마름모 · '분기 1'처럼 번호가 붙는다 |
| `end` · `kind:'bad'` | 점선 원에 × · 'BAD END 01'처럼 번호가 붙는다 |
| `end` · `kind:'normal'` · `'true'` | 코발트 별 · 금테 별 |
| `end` · `kind:'next'` | 아래 화살표 · '제2막으로' |

- 어느 칸에든 `label:'이름'`을 적으면 그 이름이 나온다. 적지 않으면 번호만 나온다. 공개 전 내용은 지어내지 않는다.
- 엔딩 번호는 위에서부터 저절로 매겨지고, 창 위의 요약(분기 수 · 엔딩 수)도 저절로 계산된다.
- 화면 읽기 프로그램에는 같은 지도가 순서 있는 목록으로 읽힌다. Esc나 바깥 클릭으로 닫으면 누른 막으로 초점이 돌아간다.

### 소식지 연결하기

`assets/js/main.js`의 `NEWSLETTER_ENDPOINT`에 폼을 받는 주소(Formspree · Getform · Google Apps Script 웹 앱 등)를 적는다.

```js
const NEWSLETTER_ENDPOINT = 'https://formspree.io/f/xxxxxxx';
```

메일 주소를 `email`이라는 이름의 폼 값으로 POST하고, 2xx로 답하면 접수된 것으로 본다. 보내는 중 · 접수됨 · 실패를 따로 보여 준다. 비워 두면 '아직 소식지 서버가 연결되지 않았다'고 알린다.

## 조작

**로비**

- 아치나 대사창을 누른다 ─ 타이핑 중이면 바로 다 보이고, 끝났으면 다음 서번트의 한마디
- 눈 버튼 ─ 대사창 · 이름표 · 메뉴를 숨기고 서번트만 보기 / 화살표 버튼 ─ 다음 서번트
- 카세트 ─ 어디를 눌러도 재생 · 정지 (상단 BGM 버튼과 같이 움직인다)
- 마스터 이름 ─ 그 마스터의 프로필 열기

**서곡 · 막**

- 화면을 누르거나 스페이스 · 엔터 · → ─ 타이핑 중이면 바로 다 보이고, 끝났으면 다음 문단
- AUTO 자동 넘기기 · SKIP 빨리 감기 · LOG 지난 문장 · ✕ 또는 Esc 나가기
- 장면이 바뀌는 연출 중에는 눌러도 넘어가지 않는다

**프로필**

- ← → 또는 이전/다음 ─ 같은 쪽(서번트끼리, 마스터끼리) 이동. 로비의 대표 서번트도 같이 바뀐다
- 탭에 초점이 있을 때 ← → ─ 탭 전환
- Esc, 바깥 클릭, ✕ ─ 닫기 (닫으면 원래 누른 자리로 초점이 돌아간다)

**그 밖에**

- 소환 연출 중 화면을 누르면 건너뛴다
- Esc는 열린 창을 닫는다

## 디자인

테마는 **'천문 기록'**이다. 낮의 화면(캐스트 · 소환 · 스토리 · 정보 · 프로필)은 결 있는 크림 종이에 코발트 잉크와 금박 테이프를 쓴 천문 노트이고, 로비는 밤으로 물든 우키하 거리 위의 은빛 별과 코발트 빛이다. 색 · 글꼴 · 부품 규칙은 [DESIGN.md](DESIGN.md)가 정한다. 새 화면이나 부품을 만들기 전에 먼저 읽는다.

- **디자인 토큰 3단** ─ `style.css` 맨 위. `--p-*`(원색, 실제 색 값은 여기에만) → `--color-*`(역할 이름, 화면은 이것만 쓴다) → 부품 안 이름(`.dock`의 `--ink` 같은). 색을 바꿀 땐 역할 줄의 연결만 바꾼다. 예전 이름(`--accent`, `--paper` …)은 역할 이름을 가리키도록 남아 있다.
- **글꼴** ─ 한글 제목은 나눔명조, 본문과 UI는 IBM Plex Sans KR(`--main`, 200~600), 서곡 같은 긴 산문은 Pretendard, 라틴 장식은 Italiana · Instrument Serif, 창 제목줄은 DotGothic16. IBM Plex Sans KR은 가장 굵은 자족이 600이라 그보다 굵게 쓰면 가짜 볼드가 생긴다.
- **정직한 상태** ─ 못 불러온 것은 못 불러왔다고 보여 준다. 배경음악은 재생 · 정지 말고도 *대기*(브라우저가 아직 재생을 허락하지 않음)와 *오류*(파일을 못 불러옴)를 따로 보여 준다. 미공개 · 잠김은 도장, `—`, 원래 문양으로 남긴다.
- **손가락 크기** ─ 터치 화면에서는 누를 자리가 44px 이상이다. 모양은 그대로 두고 누르는 범위만 넓혔다.
- **움직임 줄이기** ─ 기기에서 움직임 줄이기를 켜면 반짝임 · 궤도 회전 · 그루터기 뜯기 같은 연출이 멈춘다.
- **하단 메뉴(돋보기 독)** ─ Bencho의 "Magnifying dock"(MIT, bencho.dev/licence)을 바닐라 JS로 옮겼다. 커서와의 거리에 따라 아이콘이 커지고 떠오르며(최대 1.32배 · 양옆 둘까지), 이름 말풍선 하나가 아이콘 사이를 미끄러져 다닌다. 손가락으로는 독을 따라 쓸다가 뗀 자리의 화면이 열리고, 마우스가 없으면 아이콘 아래 이름이 항상 보인다. 숫자는 `main.js`의 `DOCK_OPT`.
- 장식 그림은 `assets/img/deco/`에 있다 ─ 별(`sparkle*.svg`), 종이 결(`grain.svg`), 낮 배경 성도(`starchart.svg`), 로비 밤하늘(`nightsky.svg`). 로비 오른쪽 위 달 일곱 개는 서번트 수이고, 공개된 서번트만 빛난다.
