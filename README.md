# Fate / Encore

전기 비주얼노벨 『Fate / Encore』 의 공개 사이트. 후쿠오카현 우키하에서 벌어지는 **제6차 성배전쟁**을 다룬다. 일곱 명의 마스터와 일곱 기의 서번트, 발신인 없는 초대장, 그리고 해가 기울면 도시에 섞여드는 설명할 수 없는 풍경.

> 본 저장소는 TYPE-MOON 작품을 좋아하는 사람이 만든 **비공식 팬 제작물**이며, 저작권자 및 관련 회사와 아무런 관계가 없습니다. 사이트에 등장하는 영령·등장인물·각본은 전부 창작이거나 퍼블릭 도메인 인물을 바탕으로 합니다.

## 구성

```
index.html              한 장으로 된 본문
assets/css/style.css    전체 스타일
assets/js/main.js        막 오름 연출 · 대화창 · 섹션 추적
```

의존성 없음. 빌드 과정 없음. `index.html` 을 그대로 열면 동작한다.

## 들어 있는 것

| 섹션 | 내용 |
| --- | --- |
| 히어로 | 막이 오르고 스포트라이트가 켜지는 1회성 연출, 7각 성배 마법진 |
| 서곡 | 우키하 성배전쟁의 세계관 소개와 발신인 없는 초대장 |
| 캐스트 | 일곱 기 중 공개된 넷과 미공개 셋. 초상을 누르면 대화창의 이름표와 대사가 바뀐다 |
| 막 구성 | 3개 루트와 분기·분량 |
| 사양 | 장르·플랫폼·공개 예정 |
| 대화창 | 화면 하단 고정. AUTO / SKIP / LOG 동작 |

### 대화창 조작

- **초상 클릭** — 해당 영령의 대사를 재생
- **대화창 클릭** — 타이핑 중이면 즉시 출력, 끝났으면 다음 대사
- **AUTO** — 캐스트를 순서대로 자동 재생
- **SKIP** — 현재 대사를 끝까지 출력
- **LOG** — 지난 대사 목록 열기 (`Esc` 로 닫기)
- **▾** — 대화창 접기

## 손보기

색과 글꼴은 `assets/css/style.css` 맨 위 `:root` 에 모여 있다.

```css
--curtain:#8C1230;   /* 커튼의 심홍 */
--gold:#C9A227;      /* 금박 */
--blush:#F6D3DC;     /* 대화창 글자색 */
```

캐스트를 바꾸려면 `index.html` 의 `.portrait` 버튼에 붙은 데이터 속성만 고치면 된다. 스크립트가 이 값을 그대로 읽어서 대화창에 쓴다.

```html
<button class="portrait" type="button" data-name="이름" data-class="클래스" data-line="대사">
```

미공개 서번트는 버튼이 아니라 `div.portrait.portrait--sealed` 로 들어가 있어서 눌리지 않는다. 진명이 정해지면 그 `<li>` 를 위의 `<button>` 꼴로 바꾸고 문양 SVG만 넣으면 공개 카드가 된다.

## 공개

GitHub Pages 로 올라간다. 저장소 **Settings → Pages → Source: `main` / `(root)`** 로 두면 끝.

## 아직 비어 있는 곳

- 세이버 · 랜서 · 라이더는 진명 미공개 상태다.
- 도로시 · 로드 · 매그 보의 대사가 `⋯⋯.` 로 비어 있다.
- 막 구성의 세 루트(세레나데 · 레퀴엠 · 앙코르)와 분기 수는 임시값이다.
- 소식지 입력란은 받는 곳이 없다. `assets/js/main.js` 의 소식지 처리 부분에 전송 코드를 넣으면 된다.
- 캐스트 초상은 클래스 상징을 넣은 아치 프레임이다. 그림이 준비되면 `.portrait__glyph` 를 `<img>` 로 바꾸면 된다.
