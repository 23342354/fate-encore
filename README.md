# Fate / Encore

전기 비주얼노벨 『Fate / Encore』 의 공개 사이트. 후쿠오카현 우키하에서 벌어지는 **제6차 성배전쟁**을 다룬다. 일곱 명의 마스터와 일곱 기의 서번트, 발신인 없는 초대장, 그리고 해가 기울면 도시에 섞여드는 설명할 수 없는 풍경.

> 본 저장소는 TYPE-MOON 작품을 좋아하는 사람이 만든 **비공식 팬 제작물**이며, 저작권자 및 관련 회사와 아무런 관계가 없습니다. 사이트에 등장하는 영령·등장인물·각본은 전부 창작이거나 퍼블릭 도메인 인물을 바탕으로 합니다.

## 구성

```
index.html              한 장으로 된 본문
assets/css/style.css    전체 스타일
assets/js/cast.js       캐릭터 설정 — 설정을 고칠 곳은 여기다
assets/js/main.js       막 오름 연출 · 대화창 · 스테이터스 · 섹션 추적
```

의존성 없음. 빌드 과정 없음. `index.html` 을 그대로 열면 동작한다.

### 대화창 조작

- **초상 클릭** — 해당 영령의 대사를 재생
- **대화창 클릭** — 타이핑 중이면 즉시 출력, 끝났으면 다음 대사
- **AUTO** — 캐스트를 순서대로 자동 재생
- **SKIP** — 현재 대사를 끝까지 출력
- **LOG** — 지난 대사 목록 열기 (`Esc` 로 닫기)
- **▾** — 대화창 접기

## 손보기

색과 글꼴은 `assets/css/style.css` 맨 위 `:root` 에 모여 있다.

```css
--curtain:#8C1230;   /* 커튼의 심홍 */
--gold:#C9A227;      /* 금박 */
--blush:#F6D3DC;     /* 대화창 글자색 */
--main:'IbmPlexSans';  /* 제목·대화창·카드 */
--sans:'Pretendard';   /* 서곡과 긴 산문 */
--display:'Italiana';  /* 라틴 대문자 */
--title:'Times New Roman';  /* 제호 */
```

제호는 `index.html` 안의 SVG 다. `textLength` 와 `lengthAdjust="spacingAndGlyphs"` 가 폭을 못 박아, 기기에 어떤 세리프가 깔려 있든 정해진 폭에 맞춰 장평이 조절된다. 글꼴은 타임스 뉴 로만, 없으면 자폭이 같은 Tinos 다. 제호 문구를 바꾸려면 SVG 의 `<text>` 내용과 `aria-label` 을 같이 고친다. `--main` 의 IBM Plex Sans KR 은 `@font-face` 로 직접 불러온다. 쓸 수 있는 굵기는 200 · 300 · 400 · 450 · 500 · 600 이며, 가장 굵은 자족이 600 이라 그보다 굵게 쓰면 브라우저가 가짜 볼드를 만든다.

캐스트를 바꾸려면 `index.html` 의 `.portrait` 버튼에 붙은 데이터 속성만 고치면 된다. 스크립트가 이 값을 그대로 읽어서 대화창에 쓴다.

```html
<button class="portrait" type="button" data-name="이름" data-class="클래스" data-line="대사">
```

마스터는 같은 카드 안의 `.portrait__master` 한 줄이다. 대화창과는 무관해서 텍스트만 고치면 된다.

### 설정 채우기

`assets/js/cast.js` 하나만 고치면 된다. 진명이 열쇠이고, 비워 두면 패널에 `—` 가 뜬다.

```js
'오스카 조로아스터': {
  gender: '남성',
  alignment: '星',
  height: '183cm',
  weight: '71kg',
  stats: { str:'C', end:'B', agi:'B', mgi:'EX', lck:'B', np:'A+' },
  npName: '에머랄드 빛 끝에서 그대를 기다리리',
  npAlias: '에우리온 아틀리에 · Eurion Atelier',  // 선택
  npType: '결계보구',                            // 선택
  np: [ '첫 문단.', '둘째 문단.', '“따옴표로 시작하면 자동으로 대사체가 된다.”' ],
  skills: [
    { kind:'클래스 스킬', name:'진지작성', rank:'B', title:'손님을 위한 별궁',
      text: [ '문단 하나가 배열 항목 하나다.', '둘째 문단.' ] }
  ],
  bio: [ '소개문도 문단 배열이다.' ]
}
```

- `stats` 의 열쇠 — `str` 근력 / `end` 내구 / `agi` 민첩 / `mgi` 마력 / `lck` 행운 / `np` 보구
- `kind` 에는 `클래스 스킬` · `보유 스킬 ①` · `고유 능력` 처럼 아무 분류나 쓸 수 있다
- `title` 은 스킬의 부제다. 없으면 `''` 로 두면 그 줄이 통째로 빠진다
- `「` `『` `“` 로 시작하는 문단은 금색 세로선이 그어진 대사체로 바뀐다
- `npAlias`(이명) · `npType`(종별) 은 적어 둔 캐릭터에게만 줄이 생긴다. 없으면 아예 나오지 않는다
- 캐릭터의 한마디는 설정이 아니라 `index.html` 의 `data-line` 이다. 대화창과 스테이터스 양쪽에 쓰인다

### 스테이터스 조작

- **카드 클릭** — 패널 열기 (대화창에도 그 서번트의 대사가 들어간다)
- **← →** 또는 이전/다음 — 공개된 서번트 사이 이동
- 탭에 포커스가 있을 때의 **← →** — 스테이터스 / 스킬 / 보구 전환
- **Esc**, 바깥 클릭, ✕ — 닫기

미공개 서번트는 버튼이 아니라 `div.portrait.portrait--sealed` 로 들어가 있어서 눌리지 않는다. 진명이 정해지면 그 `<li>` 를 위의 `<button>` 꼴로 바꾸고 문양 SVG만 넣으면 공개 카드가 된다.

## 공개

GitHub Pages 로 올라간다. 저장소 **Settings → Pages → Source: `main` / `(root)`** 로 두면 끝.

## 아직 비어 있는 곳

- 세이버 · 랜서 · 라이더는 서번트와 마스터 모두 미공개 상태다.
- 도로시 · 매그 보의 대사가 `⋯⋯.` 로 비어 있다.
- 도로시 · 매그 보는 스테이터스가 전부 `—` 다.
- 막 구성 네 막의 내용이 모두 비공개다. `index.html` 의 `.act--sealed` 를 풀고 제목·본문을 넣으면 공개 카드가 된다.
- 소식지 입력란은 받는 곳이 없다. `assets/js/main.js` 의 소식지 처리 부분에 전송 코드를 넣으면 된다.
- 캐스트 초상은 클래스 상징을 넣은 아치 프레임이다. 그림이 준비되면 `.portrait__glyph` 를 `<img>` 로 바꾸면 된다.
