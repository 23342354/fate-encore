# Fate / Encore

전기 비주얼노벨 『Fate / Encore』 의 공개 사이트. 후쿠오카현 우키하에서 벌어지는 **제6차 성배전쟁**을 다룬다. 일곱 명의 마스터와 일곱 기의 서번트, 발신인 없는 초대장, 그리고 해가 기울면 도시에 섞여드는 설명할 수 없는 풍경.

> 본 저장소는 TYPE-MOON 작품을 좋아하는 사람이 만든 **비공식 팬 제작물**이며, 저작권자 및 관련 회사와 아무런 관계가 없습니다. 사이트에 등장하는 영령·등장인물·각본은 전부 창작이거나 퍼블릭 도메인 인물을 바탕으로 합니다.

### 첫 방문 서곡

처음 들어온 사람은 `TAP TO START` 를 누르면 서곡이 바로 시작된다. 끝나면 소환 화면으로 넘어간다. 한 번 보여 주면 끝까지 봤든 중간에 나갔든 다시는 저절로 틀지 않는다 (브라우저에 `fe-intro` 로 기억). 서곡은 홈 배너와 스토리 화면에서 언제든 다시 볼 수 있다.

- 다시 확인하고 싶으면 주소 끝에 `?intro` 를 붙여 연다. 예) `https://…/fate-encore/?intro`
- `TAP TO START` 를 거치는 건, 브라우저가 사용자가 한 번 누르기 전에는 소리를 내 주지 않기 때문이다.

### 서곡 조작

- **화면을 누르거나 스페이스 · 엔터 · →** — 타이핑 중이면 즉시 출력, 끝났으면 다음 문단
- **AUTO** — 자동으로 넘기기
- **SKIP** — 빨리 감기
- **LOG** — 지난 문장 보기
- **✕, Esc** — 나가기
- 장면이 바뀌는 연출 중에는 눌러도 넘어가지 않는다

스크립트는 `assets/js/prologue.js` 의 `PROLOGUE` 다. 위에서부터 한 줄씩 실행된다. 줄의 종류는 파일 맨 위에 적혀 있다.

배경 그림은 아직 없어서 코드로 그린 임시 배경이 나온다. 그림을 찾으면 `assets/img/story/` 같은 폴더에 넣고, 같은 파일의 `PROLOGUE_ASSETS.bg` 빈칸에 경로를 적는다.

```js
bg: {
  ukiha: 'assets/img/story/ukiha.jpg',   // 저녁 무렵의 우키하
  ...
}
```

- 가로로 긴 그림이 좋다. 폰에서는 가운데 부분만 보인다.
- 첫 창문의 두 그림은 같은 구도여야 한다. 검은 화면의 불빛 → 불 꺼진 방이 둥글게 드러남 → 형광등이 깜빡이며 켜짐 순서로 겹쳐 쓰인다. 불빛 자리는 `main.js` 의 `SPOT` 과 `style.css` 의 `50.1% 41.2%` (그림 기준 가로·세로 비율)다.
- 방 장면의 봉투와 초대장은 `tools/compose-room.py` 로 다다미방 그림에 합성했다. 위치를 바꾸려면 그 파일을 고쳐 다시 실행한다.
- 몽타주 풍경을 더하거나 빼려면 `PROLOGUE_ASSETS.montage` 목록을 고친다. 순서대로 돌고, 안내문 장면이 다시 나오면 보던 곳 다음부터 이어 간다.
- 창문들 장면의 어두운 창 위치는 `main.js` 의 `windows` 와 `style.css` 의 `49.6% 44.8%` (그림 기준)다. 그림을 바꾸면 같이 고친다.
- 그림을 넣으면 그 장면의 임시 배경은 사라진다. 봉투가 열리는 것, 유리창에 비치는 형상처럼 임시 배경에 붙어 있던 연출도 같이 사라진다. 불빛, 색종이, 영주는 배경과 상관없이 나온다.
- `sfx` 에 효과음(겨울바람 · 봉투 · 발소리 · 종이), `cg` 에 일러스트(초대장을 읽는 사람들 · 손 · 시선 · 그림자)를 같은 방식으로 넣는다. `cg` 가 비어 있으면 그 자리에 지문이 자막처럼 나온다.
- 효과음은 상단 BGM 버튼을 끄면 같이 꺼진다.

## 손보기

색과 글꼴은 `assets/css/style.css` 맨 위 `:root` 에 모여 있다.

```css
--paper:#FAFAF7;     /* 종이 바탕 */
--ink:#08090B;       /* 글자 잉크 */
--accent:#366379;    /* 장미의 청록 — 라벨·선·버튼 */
--sky:#76AACF;       /* 하늘빛 리본 */
--cream:#E3D9B8;     /* 크림 리본 */
--sage:#8FA98B;      /* 세이지 리본 */
--main:'IbmPlexSans';  /* 제목·대사창·카드 */
--sans:'Pretendard';   /* 서곡과 긴 산문 */
--display:'Italiana';  /* 라틴 대문자 */
```

배색은 로고 그림에서 뽑았다. 바탕은 밝은 종이색이고, 초상 아치·카드 그림·대사창만 어두운 면이다. 어두운 면은 `:root` 바로 아래 블록에서 같은 변수 이름에 밝은 값을 다시 준다. 그래서 색을 바꿀 때는 두 블록을 같이 본다.

제호는 `assets/img/logo.png` 그림이다. 같은 이름으로 파일을 덮어쓰면 바뀐다. 가로세로 비율이 달라지면 `index.html` 의 `width` · `height` 값도 고친다. 글자가 검은색이라 어두운 바탕에서는 보이지 않는다. `--main` 의 IBM Plex Sans KR 은 `@font-face` 로 직접 불러온다. 쓸 수 있는 굵기는 200 · 300 · 400 · 450 · 500 · 600 이며, 가장 굵은 자족이 600 이라 그보다 굵게 쓰면 브라우저가 가짜 볼드를 만든다.

참전 명단은 `assets/js/main.js` 맨 위의 `ROSTER` 다. 클래스 순서대로 일곱 줄이고, `name` 이 없는 줄은 미공개 카드가 된다.

```js
{ cls: 'CASTER', name: '진명', master: '마스터 이름', line: '한마디', glyph: svg('…') },
```

`line` 은 로비 대사창과 프로필에 같이 쓰인다. `name` 은 `cast.js` 의 열쇠와 글자가 같아야 설정이 붙는다.

### 설정 채우기

`assets/js/cast.js` 하나만 고치면 된다. 진명이 열쇠이고, 비워 두면 패널에 `—` 가 뜬다.

```js
'오스카 조로아스터': {
  gender: '남성',
  alignment: '星',
  height: '183cm',
  weight: '71kg',
  stats: { str:'C', end:'B', agi:'B', mgi:'EX', lck:'B', np:'A+' },
  npName: '에머랄드 빛 끝에서 그대를 기다리리',
  npAlias: '에우리온 아틀리에 · Eurion Atelier',  // 선택
  npType: '결계보구',                            // 선택
  npRange: '10~99',                             // 선택
  npTargets: '50명',                            // 선택
  np: [ '첫 문단.', '둘째 문단.', '“따옴표로 시작하면 자동으로 대사체가 된다.”' ],
  skills: [
    { kind:'클래스 스킬', name:'진지작성', rank:'B', title:'손님을 위한 별궁',
      text: [ '문단 하나가 배열 항목 하나다.', '둘째 문단.' ] }
  ],
  bio: [ '소개문도 문단 배열이다.' ],
  lore: [                                  // 설정 탭
    { heading: '', text: [ '소제목 없는 머리말 덩어리.' ] },
    { heading: '그가 남긴 업적',
      table: { head: ['분야','대표 업적','후대의 평가'],
               rows: [ ['회화','작품명','평가'] ] },
      text: [ '표 아래에 이어지는 문단.' ] }
  ]
}
```

- `stats` 의 열쇠 — `str` 근력 / `end` 내구 / `agi` 민첩 / `mgi` 마력 / `lck` 행운 / `np` 보구
- `kind` 에는 `클래스 스킬` · `보유 스킬 ①` · `고유 능력` 처럼 아무 분류나 쓸 수 있다
- `title` 은 스킬의 부제다. 없으면 `''` 로 두면 그 줄이 통째로 빠진다
- `「` `『` `“` `‘` 로 **시작하고 닫는 따옴표로 끝나는** 문단은 청록 세로선이 그어진 대사체로 바뀐다. `“잘했어”라는 말은…` 처럼 인용으로 시작하는 서술문은 본문으로 남는다
- `**별 두 개**` 로 감싼 부분은 짙은 청록 강조가 되고, 문단 안의 `\n` 은 줄바꿈이 된다
- `lore` 는 덩어리의 배열이다. `heading` 을 비우면 소제목 없이 문단만 나오고, `table` 은 넣은 덩어리에만 그려진다. 좁은 화면에서는 표가 세로로 풀린다
- `npAlias`(이명) · `npType`(종별) · `npRange`(렌지) · `npTargets`(최대포착) 은 적어 둔 캐릭터에게만 줄이 생긴다. 없으면 아예 나오지 않는다
- 캐릭터의 한마디는 설정이 아니라 `main.js` 의 `ROSTER` 에 있는 `line` 이다

### 마스터 설정 채우기

마스터 설정은 `assets/js/masters.js` 다. 마스터 이름이 열쇠이고, 어느 서번트와 짝인지는 `ROSTER` 가 정한다.

| 항목 | 내용 |
| --- | --- |
| `gender` · `age` · `height` · `weight` | 성별 · 나이 · 신장 · 체중 |
| `affiliation` | 소속 · 직업 |
| `magic` | 마술 계통 |
| `line` | 한마디. 비우면 인용칸이 사라진다 |
| `bio` | 소개 문단 배열 |
| `lore` | 설정 탭. `cast.js` 의 `lore` 와 같은 꼴 |

비워 둔 항목은 "—" 로 나온다.

영주 그림은 `ROSTER` 의 `masterGlyph: seal('assets/img/파일.png')` 로 넣는다. 네 마스터 모두 들어가 있다 — 이치노세 류가(`seal-ryuga.png`), 마키오카 모쿠렌(`seal-mokuren.png`), 릴리안 루스텔리아(`seal-lilian.png`), 오즈 누벨(`seal-oz.png`). 서곡의 붉은 문양 장면에도 이 넷이 빨갛게 떠오른다. 그림을 다른 사람이 그렸으면 같은 줄에 `masterGlyphCredit: '@아이디'` 를 적는다. 프로필의 영주 아래에 "영주 디자인 @아이디" 가 붙는다. 배경이 투명한 PNG 를 쓴다.

### 프로필 조작

- **← →** 또는 이전/다음 — 같은 쪽(서번트끼리, 마스터끼리) 이동. 로비의 대표 서번트도 같이 바뀐다
- 탭에 포커스가 있을 때의 **← →** — 탭 전환
- **Esc**, 바깥 클릭, ✕ — 닫기

미공개 서번트를 공개하려면 `ROSTER` 의 그 줄에 `name` · `master` · `line` · `glyph` 를 채우고, `cast.js` 에 같은 이름으로 설정을 넣는다.

## 공개

GitHub Pages 로 올라간다. 저장소 **Settings → Pages → Source: `main` / `(root)`** 로 두면 끝.

## 아직 비어 있는 곳

- 세이버 · 랜서 · 라이더는 서번트와 마스터 모두 미공개 상태다.
- 오스카 조로아스터 · 카르타필루스는 설정 탭이 비어 있다.
- 마스터 넷은 이름과 짝만 있다. 나머지 설정은 `masters.js` 에 전부 빈칸이다.
- 카르타필루스의 보구 『EGO』는 본문이 불명으로만 적혀 있다.
- 스토리의 네 막이 모두 잠겨 있다. `index.html` 의 `.chapter--locked` 를 서곡처럼 `<button class="chapter">` 로 바꾸면 열린 막이 된다.
- 서곡은 붉은 문양 장면을 빼고 모든 배경에 그림이 들어가 있다. 나머지 배경 · 효과음 · 일러스트는 빈칸이라 임시 배경과 지문 자막으로 대신한다.
- 소식지 입력란은 받는 곳이 없다. `assets/js/main.js` 의 소식지 처리 부분에 전송 코드를 넣으면 된다.
- 초상은 클래스 상징을 넣은 아치와 카드다. 그림이 준비되면 `ROSTER` 의 `glyph` 자리에 `<img>` 를 넣으면 된다.
- HUD 의 령주 3 은 장식이다. 소환에 재화가 들지 않는다.
